先看各家的完整观点，再读有出处的比较。默认免费网页版，不必配置 API Key。

第一次使用 · 三步开始

  1. 完整解压 ZIP，进入 FourAIConsult 文件夹，双击 FourAIConsult.exe。不要在压缩包里运行，不要只复制 EXE。无需安装 Python。
  2. 分别登录自己的 AI 账号。每个面板可放大。打开「使用与帮助」，检查输入框；检查通过不代表登录、额度或网站服务一定可用。
  3. 输入一个需要比较的问题。点击「开始会诊」。在报告里查看「完整回答」，再选择「生成比较报告」，确认把材料发给哪家模型后开始。

适合先试：两种工作方案比较、学习方法对照、代码实现思路。首次测试不要使用私人或保密资料。

某一家没有回答，怎么办？

其他模型可以继续；失败面板可单独重试。先确认登录与网络，验证码需自行完成。候补模型在「会诊阵容」里选择，替换后先登录，再开始新一轮。报告会说明哪些模型缺席。

免费综合依赖网站的登录、额度及页面适配，可能中断。已完成的分析会保留，可从历史进入报告继续。API 加强版是可选付费通道，不是免费模式的使用前提。

记录在哪里？升级会丢吗？

「使用与帮助 → 数据与备份」显示当前实际数据目录。默认在 %LOCALAPPDATA%\FourAIConsult，与安装文件夹分开。每收到一家回答就保存，重启后从历史查看；尚未结束的网页任务不会自动续传。

升级前先备份，右下角托盘选择「彻底退出」，再解压新版。不要同时运行两个版本。记录异常时不要删除数据库或覆盖数据目录，先联系邀请你的人。

反馈问题，只要告诉我们这四件事

做了什么 → 期望什么 → 实际发生什么 → 能否重复。

软件内「使用与帮助 → 反馈问题」有可复制模板和无原文诊断摘要。文件不会自动上传，你可以先查看，再自行发送给邀请你的人。

私人备份不要当作诊断发送。它包含你的问题、回答和报告。截图前遮住个人信息、账号和聊天内容。

这是 Windows 64 位小范围测试版本，不是承诺所有设备、网站或问题都已验证的正式版。若系统阻止启动，请保留提示并反馈，不要关闭安全软件。AI 对比不是事实核验，多家意见一致也不代表正确；重要决定请核对原始依据。

本地历史与登录资料不会主动上传到本软件服务器。提问由选中的模型网站处理；生成综合前会再次确认材料与接收方。不要把已使用过的数据文件夹打包给别人。
