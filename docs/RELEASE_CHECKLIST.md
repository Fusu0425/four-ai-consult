# 发布检查表

- 用户明确批准项目许可证。
- 源码、完整公开 Git 历史、图片和发行包检查，不包含私人数据、密钥、账号或录屏。
- 版本一致，文档链接有效，第三方许可、版权声明和匹配版本源码获取说明齐全。
- Ruff、单元和 Qt 集成测试通过；跳过项单独说明。
- 二进制目录审计、ZIP CRC、SHA-256、全新数据目录启动检查通过。
- 标签指向实际构建源码提交，保留依赖版本记录；不覆盖已发布同名版本的不同内容。
- 在 GitHub 标为 Pre-release，写明真实网站和第二台电脑尚未验收的边界。
- 发布后检查公开访问和附件下载，并核对文件哈希。
- 真实模型与独立用户验证达标后再扩大测试，不把自动化测试写成已完成用户验收。
